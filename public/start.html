Как зайти на сервер

Адрес сервера

Игра: Minecraft Java Edition. Проверяем сервер…

Инструкция

  1. Запустите Minecraft Java Edition.
  2. Откройте Сетевая игра → Добавить сервер.
  3. Вставьте IP и нажмите Готово.
  4. Зайдите и прочитайте правила.
